⏱️ 洗い物と油汚れを最小限にしつつ、揚げ物・焼き物を熱々で揃える効率順のタイムラインです。

Phase 1：下ごしらえ（火を使う前に一気に行う）

所要目安：15〜20分
STEP 1
  • 【③ ポテト】じゃがいもの皮をむき一口大に切り、コンソメ＋重曹入りの湯で茹で始める茹で上がったら湯を切り2分乾かし、鍋を振って表面をボロボロにしてザルで冷ましておく
  • 【① しいたけ】軸の硬い先端を落とし、傘を半分に切ってポリ袋のタレに漬け込む醤油・みりん・酒・オイスターソース・砂糖・鶏ガラ・ニンニク・生姜を袋で混ぜてなじませる
  • 【④・⑤ 玉ねぎ＆豚こま】玉ねぎをカットし、豚こま肉にそれぞれ下味を揉み込む④用は1cm輪切り＋豚こま下味／⑤用は玉ねぎ1/2個＋豚こま200g（醤油小1・酒大1・片栗粉大3）
  • 【④ 成形】玉ねぎ（片面に片栗粉）で大葉・スライスチーズ・下味豚こまを挟む片栗粉の面を内側にして挟み、焼くだけの状態にする
  • 【② 豆腐】木綿豆腐の水分を拭き取り、スライスチーズを挟んで下味＆片栗粉をまぶす1/4厚さをさらに横半分に切りチーズを挟む → 鶏ガラ → 片栗粉を全面にコーティング
  • 【③・④・⑤ 合わせ調味料】各種タレ・ソースを小鉢で混ぜておく③ディップソース／④絡めダレ／⑤味噌ダレ（味噌小2・醤油大1・酒大1）

Phase 2：加熱・仕上げ（フライパン・揚げ鍋の順）

所要目安：15〜20分
STEP 2
  • 【④ 玉ねぎチーズ挟み焼き】蓋をして中火4分 → 裏返して弱火5分蒸し焼き＋タレ絡めじっくり蒸し焼きにしている間に隣のコンロで揚げ物や豆腐を進める
  • 【② 闇つき豆腐チーズ】卵焼き器にピザ用チーズを薄く敷き、豆腐サンドを両面こんがり焼く表面こんがり・裏面はチーズを足してパリトロに仕上げる
  • 【⑤ 豚こまスタミナ丼】フライパンで豚こまと玉ねぎを炒め、味噌ダレを絡めて丼に盛る仕上げに卵をトッピング
  • 【① しいたけ → ③ ポテトの順で揚げる】揚げたてを食卓へ！①片栗粉をまぶして約3分（後半空気にあてる）→③冷ましたポテトをきつね色に揚げて塩・黒胡椒

① 【10分で簡単】しいたけ唐揚げ

料理研究家ゆかりのおうちで簡単レシピ
▶ YouTube動画を開く
揚げ物
📌 材料・分量
  • しいたけ（適量）軸を切り落とし傘は半分に切る。軸は硬い先端のみ切り落とす
  • ポリ袋調味料：醤油・みりん・酒・オイスターソース・砂糖・鶏ガラスープの素・おろしニンニク・おろし生姜
  • 片栗粉・揚げ油（各適量）
🍳 手順
  • 1. 軸の硬い先端を切り落とし、傘を半分に切る。
  • 2. ポリ袋に調味料をすべて入れてよく混ぜ、しいたけ（傘・軸）を入れてシャカシャカ振りなじませる。
  • 3. 片栗粉をまぶし、油で約3分揚げる（1分で裏返し、2分経過後から空気にあてながら揚げるとカリッと仕上がる）。

② 闇つき豆腐チーズ（ミルフィーユサンド）

飲食店独立学校 / こうせい校長
▶ YouTube動画を開く
焼き物
📌 材料・分量
  • 木綿豆腐：130g×3個パック（水切り不要）
  • とろけるスライスチーズ：2枚
  • 鶏ガラスープの素・片栗粉・ピザ用チーズ（各適量）
🍳 手順
  • 1. 豆腐の余分な水気を拭き取り、1/4の厚さにカットしてからさらに横半分に切る。
  • 2. 豆腐の大きさに切ったスライスチーズを挟み、表面に鶏ガラスープの素→片栗粉の順にしっかりまぶす。
  • 3. 卵焼き器にピザ用チーズを薄く均一に敷き、豆腐を間隔をあけて並べて弱火〜中火でこんがり焼く。
  • 4. 器を使ってひっくり返し、反対面にも少なめのチーズ（余ったスライスチーズ等）を敷いてじっくり焼く。

③ スーパークリスピーポテト

ポテトのタカタク🥔
▶ YouTube動画を開く
揚げ焼き
📌 材料・分量
  • じゃがいも（適量・皮をむき一口大）／茹で汁（水・コンソメ・重曹）
  • ソース：ケチャップ・マヨネーズ・レモン汁・チリパウダー（多め推奨）
  • 仕上げ：塩・ブラックペッパー・揚げ油
🍳 手順
  • 1. 水・コンソメ・重曹を沸騰させ、一口大のじゃがいもを「周りが崩れ出し少し硬い」くらいまで茹でる。
  • 2. 湯を切って2分乾かし、鍋に戻して思いっきり振って表面をボロボロにし、ザルに広げて冷ます。
  • 3. ソース材料を混ぜる。フライパンに油を熱してポテトを中火で転がしながらこんがりきつね色に揚げ焼きする。
  • 4. 油を切り、熱いうちに塩・ブラックペッパーをまぶしてソースを添える。

④ 豚こまがジューシーな玉ねぎチーズ挟み焼き

簡単レシピ 東京OLむむちゃん
▶ YouTube動画を開く
蒸し焼き
📌 材料・分量
  • 玉ねぎ（1cm厚さの輪切り）・豚こま切れ肉（下味を揉み込む）
  • 大葉・スライスチーズ・片栗粉（玉ねぎの片面用）・合わせダレ
🍳 手順
  • 1. 玉ねぎの片面に片栗粉をまぶし、大葉・スライスチーズ・下味豚こまを乗せ、もう1枚の玉ねぎ（片栗粉面を内側）で挟む。
  • 2. 油をひいたフライパンに並べ、蓋をして中火で4分蒸し焼きにする。
  • 3. 裏返して蓋をし、弱火でさらに5分火を通す。
  • 4. タレを加え、スプーンで上からかけながら全体に照りが出るまで絡める。

⑤ 豚こまと玉ねぎのスタミナ丼

ポテヒロの楽メシ（2人分）
▶ YouTube動画を開く
丼もの
📌 材料・分量（2人分）
  • 豚こま肉：200g／玉ねぎ：1/2個（約100g）／卵：1個
  • 肉の下味：醤油 小さじ1／酒 大さじ1／片栗粉 大さじ3
  • タレ：味噌 小さじ2／醤油 大さじ1／酒 大さじ1（※お好みでニンニク・生姜）
🍳 手順
  • 1. 玉ねぎを切り、豚こま肉に下味（醤油小1・酒大1・片栗粉大3）を揉み込む。タレ材料を混ぜておく。
  • 2. フライパンに油を熱し、豚こま肉と玉ねぎを炒め合わせて火を通す。
  • 3. タレを回し入れて全体に絡め、ごはんの上に盛り付けて卵をトッピングする。
